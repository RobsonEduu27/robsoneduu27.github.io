This policy explains how Channel Dashboard (the "App") handles data. The App is a personal tool used only by the owner of the YouTube channels it reads.

Data the App accesses

With the channel owner's permission, the App uses Google OAuth with these read-only scopes:

  • youtube.readonly — channel and video information;
  • yt-analytics.readonly — channel analytics reports;
  • yt-analytics-monetary.readonly — estimated revenue reports.

How the data is used

The data is used only to build reports about the owner's own channels, shown on the owner's computer. The App does not sell, rent, share or transfer this data to anyone, does not use it for advertising, and does not use it to train AI models.

Storage and security

Access tokens are stored only on the owner's computer. Reports stay on that computer. No data is sent to any server operated by the App; the App has no server.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the local token files also removes the App's access on that computer.

Google API Services

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The App uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Changes

Any change to this policy will be published on this page with a new date.
